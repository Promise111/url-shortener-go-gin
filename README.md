# URL Shortener (Go + Gin)

HTTP API that stores long URLs, issues a short code, and redirects public visitors to the original address. Link CRUD belongs to the logged-in user.

Stack: **Go**, **Gin**, **PostgreSQL** (`pgx` pool), **bcrypt** + **JWT** (HS256), **Swag** for OpenAPI, **Air** for live reload.

## What works today

- Register and login under `/api/v1/auth`. Login returns a JWT (5 hour `exp`)
- Link create, list, get, update, and delete under `/api/v1/links` require `Authorization: Bearer <token>`. Rows are scoped by `user_id` (owner IDOR: other users’ ids/codes are **404**)
- Optional `expires_at` on create and update (RFC3339 only; a set timestamp must be in the future). On **PATCH**, JSON `null` or a blank string clears expiry; omitting the field leaves it as-is
- Optional `status` (`active` or `disabled`) and `max_clicks` (≥ 5, or omit/`null` for unlimited). Create defaults `status` to `active`. The client cannot set `expired`
- On **PATCH**, JSON `null` on `max_clicks` clears the cap; omitting the field leaves it as-is
- Public redirect: `GET /{shortCode}` → **307 Temporary Redirect** (no auth). Unknown codes are **404**. Disabled, expired (time or click cap), or a lost increment race are **410 Gone**. Clicks increment only on 307
- Create generates a 10-character base62 code and retries the insert up to **3** times if Postgres reports a unique `short_code` (`23505`). Optional custom `short_code` on create: alphanumeric, 3–20 chars, stored lowercased; reserved words **422**; already taken **409**
- Per-IP rate limits on **create** and **public redirect** (token bucket). Over limit → **429**
- Health check
- Swagger UI at `/swagger/index.html` with **BearerAuth** on protected link operations

Not implemented yet: Redis cache, job queue, refresh tokens, email verify.

## Why two kinds of URL

CRUD is an authenticated API. A short link is something a person shares.

| Kind | Mounted on | Auth | Example |
|---|---|---|---|
| Auth | `/api/v1/auth` | No | `POST /api/v1/auth/login` |
| Link API | `/api/v1/links` | Bearer JWT | `GET /api/v1/links/1` returns JSON for **your** row |
| Public | server root | No | `GET /abc123` redirects to the long URL |

Gin treats `/:id` and `/:shortCode` as the same pattern. Public redirect is `GET /:shortCode`. Owner JSON lookup by code is `GET /api/v1/links/code/:shortCode` (static `code` so it does not clash with `/:id`).

Redirect is **307** (temporary), not 301/308. Links can be patched or expire later; a permanent redirect would be cached by browsers and skip this server.

## Project layout

```text
cmd/shortener-api/     # process entrypoint
  main.go              # config, DB, swagger host, listen
  docs/                # generated by swag (do not edit by hand)
internal/
  config/              # load .env → Config (includes JWT_SECRET)
  database/            # pgx pool; unique-violation helper (SQLSTATE 23505)
  handler/             # HTTP adapters
    link_handler.go    # JSON CRUD (owner-scoped)
    user_handler.go    # register, login, JWT
    redirect_handler.go
    health_handler.go
    response.go
  middleware/          # JWT auth + per-IP rate limiter
  model/               # Links, Users
  repository/          # SQL (takes context.Context; 5s timeout on the request ctx)
  router/              # Gin routes
  shortcode/           # random base62 short-code generator
migrations/            # Postgres DDL (000001–000006)
```

Request flow: **router → auth middleware (link group) → handler → repository → Postgres**. Handlers pass `c.Request.Context()`; the repository wraps it with a 5 second timeout.

2. Apply migrations in order (`000001` … `000006`). `000005` adds `NOT NULL user_id` on `links`; empty the table first if you already have rows without an owner.

| `JWT_SECRET` | HMAC-SHA256 key for issuing and verifying JWTs |
| `PORT` | HTTP listen port and Swagger host |

## Auth

Passwords are stored with **bcrypt** (length **8–72**; 72 is bcrypt’s byte limit). Login looks up by **email or username** (at least one required after trim; values are lowercased to match register). If both are sent, **email wins**. Soft-deleted users (`deleted_at IS NOT NULL`) are treated as unknown (**401**). Wrong user or password → **401** `"Invalid credentials."` Duplicate email/username on register → **409**. Unexpected DB errors on register → **500**.

Successful login (**200**) returns `data.user` (no password hash; model tag `json:"-"`) and `data.token`.

Send on every `/api/v1/links` request:

```http
Authorization: Bearer <token>
```

The scheme is `Bearer` (capital B) plus a space. Claims: `id`, `email`, `username`, `exp` (Unix seconds, 5 hours). Middleware checks HS256 and `jwt.Parse` validity, then `c.Set("user_id", id)`. Handlers never take `user_id` from JSON.

## HTTP API

Base URL (default): `http://localhost:8003`

JSON as `Content-Type: application/json`. Interactive docs: `/swagger/index.html`.

### Conventions

Success (except delete and redirect):

```json
{ "status": true, "message": "...", "data": {} }
```

Error:

```json
{ "status": false, "message": "..." }
```

`expires_at` is **RFC3339 only** (example `2027-04-08T00:00:00Z`). Date-only strings are rejected. Create uses `*time.Time` (RFC3339, or omit/`null`). PATCH also accepts JSON `null` / blank strings to clear expiry.

`max_clicks` is a JSON integer (≥ 5) or omit/`null` (unlimited). PATCH `{ "max_clicks": null }` clears the cap. `status` on write is `active` or `disabled` only.

**401** — missing/invalid Bearer token (link API).  
**429** (create and public redirect only):

```json
{ "status": false, "message": "Too many requests" }
```

| Method | Path | Auth | Action |
|---|---|---|---|
| GET | `/api/v1/health` | No | Health |
| POST | `/api/v1/auth/register` | No | Register |
| POST | `/api/v1/auth/login` | No | Login (JWT) |
| POST | `/api/v1/links` | Bearer | Create |
| GET | `/api/v1/links` | Bearer | List **your** links (paginated) |
| GET | `/api/v1/links/{id}` | Bearer | Get by id (your row) |
| GET | `/api/v1/links/code/{shortCode}` | Bearer | Get by short code (your row) |
| PATCH | `/api/v1/links/{id}` | Bearer | Update |
| DELETE | `/api/v1/links/{id}` | Bearer | Delete |
| GET | `/{shortCode}` | No | Public redirect |

### `GET /api/v1/health`

**200**

```json
{ "status": true, "message": "💪 Shortener API is up and running!" }
```

### `POST /api/v1/auth/register`

```json
{
  "email": "hello@hi.com",
  "password": "myPass123",
  "username": "randomgee"
}
```

Email, password (8–72), username (3–30) required. Email and username are stored trimmed and lowercased.

**201** — `data` is the user (`id`, `email`, `username`, timestamps; no password hash).  
**400** — validation. **409** — email or username taken. **500**.

### `POST /api/v1/auth/login`

```json
{
  "email": "hello@hi.com",
  "password": "myPass123"
}
```

Or `username` instead of `email`. If both are present, email is used. Password is required (8–72).

**200** — `{ "status": true, "data": { "user": { ... }, "token": "eyJ..." } }`.  
**400** — neither email nor username, or bind/validation. **401** — unknown, soft-deleted, or bad password. **500**.

### `POST /api/v1/links`

Create a short link owned by the JWT user. `long_url` required (`url`, max 2048). `expires_at` optional; if set, must be in the future. `short_code` optional (`alphanum`, min 3, max 20). Omit it (or send empty) to generate a 10-character code. `max_clicks` optional (integer ≥ 5); omit or `null` means unlimited. `status` optional (`active` or `disabled`); omit means `active`. Do not send `expired`. Do not send `user_id`.

```json
{
  "long_url": "https://example.com/very/long/path",
  "expires_at": "2027-04-08T00:00:00Z",
  "short_code": "docs",
  "max_clicks": 50,
  "status": "active"
}
```

Custom codes are trimmed and lowercased. Reserved names (`api`, `health`, `links`, `swagger`) are rejected so they cannot shadow `/api`, `/health`, `/links`, or `/swagger`.

**201** — `data` is the link (`id`, `long_url`, `short_code`, `expires_at`, `clicks`, `status`, `max_clicks`, `user_id`, `created_at`, `updated_at`).  
**400** — validation. **401**. **409** — custom `short_code` already taken. **422** — reserved `short_code`. **429** — per-IP create limit. **500** — server/DB, including after three unique collisions on a **generated** code.

Share `http://localhost:8003/{short_code}` using `data.short_code`.

### `GET /api/v1/links`

Query (all optional):

| Name | Default | Notes |
|---|---|---|
| `page` | `1` | Must be > 0 or the default is kept |
| `limit` | `10` | Capped at `100` |

Lists **your** rows only (including disabled and expired), newest first. `total` is `COUNT(*)` for that `user_id`. Public redirect still returns **410** for dead links.

**200** — `{ status, message, data, total, totalPage, page, limit }`.  
**401**. **500**.

### `GET /api/v1/links/{id}`

`id` is a numeric path param (`int64`).

**200** — one of **your** links (disabled and expired rows are returned; public redirect still **410**).  
**400** — `id` not an integer. **401**. **404** — no row **or** the row belongs to someone else. **500**.

### `GET /api/v1/links/code/{shortCode}`

Owner JSON lookup. Path param is matched **exactly** as stored (generated codes are mixed-case; custom codes were lowercased on create).

**200** — your link. **401**. **404** — unknown or not yours. **500**.

This is not the public redirect. Visitors use `GET /{shortCode}`.

### `PATCH /api/v1/links/{id}`

JSON **body is required**. At least one of `long_url`, `expires_at`, `status`, or `max_clicks` must be present (`expires_at` and `max_clicks` count as present even when `null`).

```json
{ "long_url": "https://example.com/new" }
```

Pause a link:

```json
{ "status": "disabled" }
```

Clear expiry or the click cap (same endpoint):

```json
{ "expires_at": null }
```

```json
{ "max_clicks": null }
```

For `expires_at`, `""` and whitespace-only strings are treated as null. For `max_clicks`, send a JSON integer or `null` (not a string). **Omit** a field to leave the stored value unchanged.

`status` may be `active` or `disabled` only. A set `max_clicks` must be ≥ 5.

**200** — updated link in `data`.  
**400** — bad id, bind/validation, or empty patch. **401**. **404**. **500**.

### `DELETE /api/v1/links/{id}`

**204** — empty body (success).  
**400** — bad id. **401**. **404** — no row or not yours. **500**.

### `GET /{shortCode}`

Public. Not under `/api/v1`. Gin param name is `shortCode`. Lookup is by `short_code` (exact match). No JWT.

**404** — no row.  
**410** — row exists but is not live. Clicks are not incremented.

| Cause | Message |
|---|---|
| `status` is `disabled` | `This link has been disabled.` |
| Clock expiry, `status` is `expired`, or `clicks` already at `max_clicks` | `This link has expired.` |
| Increment updated 0 rows (another request used the last click, or the row was disabled between lookup and update) | `This link is no longer available.` |

**307** — live link. `Location` is `long_url`. Then `clicks = clicks + 1` where `status = 'active'`, the row is not past `expires_at`, and `max_clicks` is null or `clicks < max_clicks`.  
**429** — per-IP redirect limit. **500**.

```text
http://localhost:8003/{short_code}
```

## Short codes

`shortcode.Generate(n)` draws `n` random bytes (`crypto/rand`) and maps each byte onto a 62-character alphabet (`0-9`, `a-z`, `A-Z`). The argument is the **output length**: when `short_code` is omitted, create calls `Generate(10)` (**10 characters**). The `links.short_code` column is `VARCHAR(64)` with a `UNIQUE` constraint.

Custom create: client sends `short_code` → trim + lowercase → reject reserved (`api`, `health`, `links`, `swagger`) with **422** → `INSERT`. Duplicate custom code is **409** (no retry). Generated codes still retry up to **3** times on `23505`.

`Generate` does not talk to the database. Uniqueness is the unique index, not a `SELECT` before insert.

## Rate limiting

In-memory token buckets (`golang.org/x/time/rate`), **one bucket per client IP** (`c.ClientIP()`). Create and redirect each have their own store and policy. Health, auth, list, get, patch, and delete are **not** limited.

| Route | Refill | Burst |
|---|---|---|
| `POST /api/v1/links` | 1 token every 6 seconds (`rate.Every(6s)`) | 3 |
| `GET /{shortCode}` | 5 tokens per second | 10 |

Over limit → **429** `{ "status": false, "message": "Too many requests" }`. The handler (and Postgres) does not run.

Idle IPs are dropped from the map after **10 minutes** of no hits (janitor every **1 minute**). A returning IP gets a fresh limiter (full burst). Locally, curl and the browser often share `127.0.0.1`, so they share one create bucket. Behind a reverse proxy, configure Gin trusted proxies or every client may look like one IP.

## Swagger

Comments live on the handler functions. Generated files: `cmd/shortener-api/docs/`.

UI: `http://localhost:8003/swagger/index.html`

Link operations use `@Security BearerAuth`. Scheme is declared in `main.go` (`@securityDefinitions.apikey`, header `Authorization`). Auth is **not** a Parameters field: use **Authorize** (top right). Paste `Bearer <token>` (word `Bearer`, space, JWT). Hard-refresh if the lock does not appear after `swag init`. Confirm the running spec at `/swagger/doc.json` contains `securityDefinitions`.

After you change `// @Router` / `// @Param` / `// @Security` comments:

```bash
swag init -g ./cmd/shortener-api/main.go -o ./cmd/shortener-api/docs --parseInternal
```

`--parseInternal` is required because handlers sit under `internal/`.

### BasePath `/`

CRUD, auth, and the public redirect do not share one prefix, so BasePath is `/`:

- `// @BasePath /` in `main.go`
- `docs.SwaggerInfo.BasePath = "/"` at runtime (this overrides the comment if they differ)

Documented URL = BasePath + `@Router`. With BasePath `/`, `@Router` must be the **full** path Gin actually serves:

| Operation | `@Router` |
|---|---|
| Health | `/api/v1/health [get]` |
| Register / login | `/api/v1/auth/register [post]` / `/api/v1/auth/login [post]` |
| Create / list | `/api/v1/links [post]` / `[get]` |
| Get / patch / delete | `/api/v1/links/{id} [...]` |
| Get by code | `/api/v1/links/code/{shortCode} [get]` |
| Redirect | `/{shortCode} [get]` |

Swag uses `{shortCode}`, not Gin’s `:shortCode`. Path type for a short code is `string`, not `int`.

Do not document the redirect as `/api/v1/links/{shortCode}` — that is not the live route.

## Data model

Table `users` (migration `000004`):

| Column | Notes |
|---|---|
| `id` | UUID, `gen_random_uuid()` |
| `email` | unique, non-empty |
| `password_hash` | bcrypt, never returned on register/login JSON |
| `username` | unique, non-empty |
| `deleted_at` | nullable soft delete; login/get-by-email/username/id require `deleted_at IS NULL` |
| `created_at` / `updated_at` | defaults |

`UNIQUE` on email and username already creates indexes. Extra duplicate indexes were dropped in `000006`.

Table `links`:

| Column | Notes |
|---|---|
| `id` | `BIGSERIAL` |
| `long_url` | non-empty, max 2048 chars |
| `short_code` | unique, non-empty, max 64 |
| `expires_at` | nullable timestamptz |
| `status` | enum `active` / `disabled` / `expired`; `NOT NULL DEFAULT 'active'` |
| `max_clicks` | nullable bigint; `NULL` = unlimited; if set, must be `> 0` (API create/PATCH also require ≥ 5) |
| `clicks` | default 0; incremented on a successful public redirect (307), not on 410 |
| `user_id` | UUID `NOT NULL REFERENCES users(id) ON DELETE CASCADE` (`000005`) |
| `created_at` / `updated_at` | default `NOW()`; PATCH sets `updated_at = NOW()` |

Indexes (migration `000002`): `expires_at` (partial, non-null), `clicks`, `created_at DESC`.  
Index (migration `000003`): `status`. Enum type `link_status` is created in `000003`.  
Index (migration `000005`): `user_id` (FK, not unique — many links per user).
