# URL Shortener (Go + Gin)

HTTP API that stores long URLs, issues a short code, and redirects public visitors to the original address.

Stack: **Go**, **Gin**, **PostgreSQL** (`pgx` pool), **Swag** for OpenAPI, **Air** for live reload.

## What works today

- Create, list, get, update, and delete links under `/api/v1`
- Optional `expires_at` on create and update (a set timestamp must be in the future). On **PATCH**, `null`, `""`, or `" "` clears expiry; omitting the field leaves it as-is
- Public redirect: `GET /{shortCode}` → **307 Temporary Redirect**
- Health check
- Swagger UI at `/swagger/index.html`

Not implemented yet: auth (`JWT_SECRET` is loaded but unused), skip redirect when the link is expired (lookup does not filter `expires_at`; increment does), short-code collision retries.

## Why two kinds of URL

CRUD is an API. A short link is something a person shares.

| Kind | Mounted on | Example |
|---|---|---|
| API | `/api/v1` | `GET /api/v1/links/1` returns JSON |
| Public | server root | `GET /abc123` redirects to the long URL |

They cannot share `GET /api/v1/links/:param`. Gin treats `/:id` and `/:shortCode` as the same pattern, so the redirect lives on `GET /:shortCode` instead.

Redirect is **307** (temporary), not 301/308. Links can be patched or expire later; a permanent redirect would be cached by browsers and skip this server.

## Project layout

```text
cmd/shortener-api/     # process entrypoint
  main.go              # config, DB, swagger host, listen
  docs/                # generated by swag (do not edit by hand)
internal/
  config/              # load .env → Config
  database/            # pgx pool
  handler/             # HTTP adapters
    link_handler.go    # JSON CRUD
    redirect_handler.go
    health_handler.go
    response.go
  model/               # Link struct
  repository/          # SQL
  router/              # Gin routes
  shortcode/           # random hex short-code generator
migrations/            # Postgres DDL
```

Request flow: **router → handler → repository → Postgres**.

## Setup

1. Create a database (name is up to you).
2. Apply the SQL in `migrations/` in order (`000001`, then `000002`).
3. Copy the env vars below into a `.env` at the repo root (that file is gitignored):

```env
DATABASE_URL=postgres://USER:PASSWORD@localhost:5432/DBNAME?sslmode=disable
JWT_SECRET=change-me
PORT=8003
```

`config.Load()` uses `godotenv` and requires `.env` to exist. It maps:

| Env var | Used for |
|---|---|
| `DATABASE_URL` | pgx connection string |
| `JWT_SECRET` | loaded only; no auth yet |
| `PORT` | HTTP listen port and Swagger host |

## HTTP API

Base URL (default): `http://localhost:8003`

No authentication. Send JSON as `Content-Type: application/json`. Interactive docs: `/swagger/index.html`.

### Conventions

Success (except delete and redirect):

```json
{ "status": true, "message": "...", "data": {} }
```

Error:

```json
{ "status": false, "message": "..." }
```

`expires_at` is RFC3339 (example `2027-04-08T00:00:00Z`). Create uses `*time.Time` (RFC3339 or omit/`null`). PATCH also accepts JSON `null` / blank strings to clear expiry.

| Method | Path | Action |
|---|---|---|
| GET | `/api/v1/health` | Health |
| POST | `/api/v1/links` | Create |
| GET | `/api/v1/links` | List (paginated) |
| GET | `/api/v1/links/{id}` | Get by id |
| PATCH | `/api/v1/links/{id}` | Update |
| DELETE | `/api/v1/links/{id}` | Delete |
| GET | `/{shortCode}` | Public redirect |

### `GET /api/v1/health`

**200**

```json
{ "status": true, "message": "💪 Shortener API is up and running!" }
```

### `POST /api/v1/links`

Create a short link. `long_url` required (`url`, max 2048). `expires_at` optional; if set, must be in the future.

```json
{
  "long_url": "https://example.com/very/long/path",
  "expires_at": "2027-04-08T00:00:00Z"
}
```

**201** — `data` is the link (`id`, `long_url`, `short_code`, `expires_at`, `clicks`, `created_at`, `updated_at`).  
**400** — validation. **500** — server/DB.

Share `http://localhost:8003/{short_code}` using `data.short_code`.

### `GET /api/v1/links`

Query (all optional):

| Name | Default | Notes |
|---|---|---|
| `page` | `1` | Must be > 0 or the default is kept |
| `limit` | `10` | Capped at `100` |

Lists non-expired rows (`expires_at IS NULL OR expires_at > NOW()`), newest first.

**200**

```json
{
  "status": true,
  "message": "Links fetched successfully!",
  "data": [],
  "total": 0,
  "totalPage": 0,
  "page": 1,
  "limit": 10
}
```

**500** — server/DB.

### `GET /api/v1/links/{id}`

`id` is a numeric path param (`int64`).

**200** — `{ status, message, data }` with one link.  
**400** — `id` not an integer. **404** — no row. **500** — server/DB.

### `PATCH /api/v1/links/{id}`

JSON **body is required**. At least one of `long_url` or `expires_at` must be present (`expires_at` counts as present even when `null`).

```json
{ "long_url": "https://example.com/new" }
```

Clear expiry (same endpoint):

```json
{ "expires_at": null }
```

`""` and whitespace-only strings are treated as null. **Omit** `expires_at` to leave the stored value unchanged.

**200** — updated link in `data`.  
**400** — bad id, bind/validation, or empty patch. **404**. **500**.

### `DELETE /api/v1/links/{id}`

**204** — empty body (success).  
**400** — bad id. **404** — if the repository reports no row. **500**.

### `GET /{shortCode}`

Public. Not under `/api/v1`. Gin param name is `shortCode`.

**307** — `Location` is `long_url`. Then increments `clicks` (`clicks = clicks + 1` where the code exists and is not expired).  
**404** — unknown `short_code`. **500**.

Lookup does **not** currently filter expiry, so an expired code can still redirect; the increment `WHERE` will not bump `clicks` for expired rows.

```text
http://localhost:8003/{short_code}
```

## Short codes

`shortcode.Generate(n)` reads `n` random bytes and hex-encodes them (`%x`). Each byte becomes two characters, so `Generate(10)` is **20 hex characters** (`0-9a-f`). The `links.short_code` column is `VARCHAR(64)`.

There is no retry yet if Postgres rejects a duplicate `short_code`.

## Swagger

Comments live on the handler functions. Generated files: `cmd/shortener-api/docs/`.

UI: `http://localhost:8003/swagger/index.html`

After you change `// @Router` / `// @Param` comments:

```bash
swag init -g ./cmd/shortener-api/main.go -o ./cmd/shortener-api/docs --parseInternal
```

`--parseInternal` is required because handlers sit under `internal/`.

### BasePath `/`

CRUD and the public redirect do not share a prefix, so both of these are `/`:

- `// @BasePath /` in `main.go`
- `docs.SwaggerInfo.BasePath = "/"` at runtime (this overrides the comment if they differ)

Documented URL = BasePath + `@Router`. With BasePath `/`, `@Router` must be the **full** path Gin actually serves:

| Operation | `@Router` |
|---|---|
| Health | `/api/v1/health [get]` |
| Create / list | `/api/v1/links [post]` / `[get]` |
| Get / patch / delete | `/api/v1/links/{id} [...]` |
| Redirect | `/{shortCode} [get]` |

Swag uses `{shortCode}`, not Gin’s `:shortCode`. Path type for a short code is `string`, not `int`.

Do not document the redirect as `/api/v1/links/{shortCode}` — that is not the live route.

## Data model

Table `links`:

| Column | Notes |
|---|---|
| `id` | `BIGSERIAL` |
| `long_url` | non-empty, max 2048 chars |
| `short_code` | unique, non-empty, max 64 |
| `expires_at` | nullable timestamptz |
| `clicks` | default 0; incremented on public redirect when the row is not expired |
| `created_at` / `updated_at` | default `NOW()` |

Indexes (migration `000002`): `expires_at` (partial, non-null), `clicks`, `created_at DESC`.
